# Security policy

## Scope

This project is a data-analysis and machine-learning portfolio repository. It
does not run a service and does not process personal data at runtime. The main
security-relevant surface is the dependency chain (`requirements.txt`).

## Supported versions

The `main` branch is the only supported version.

## Reporting a vulnerability

If you find a security issue — for example in a dependency or in how the data
is handled — please report it privately:

- Open a [private security advisory](https://github.com/panteamkhh/hotel-cancellation-prediction/security/advisories/new), or
- Email pantea.mkh18@gmail.com

Please include the affected file or dependency, a description of the issue and
steps to reproduce. You can expect an acknowledgement within a few days.

## Data

The dataset contains no personally identifiable information: it has no names,
emails or payment details, only booking attributes and an anonymised country of
origin. It is safe to commit and share, which is why it lives in this repo.
